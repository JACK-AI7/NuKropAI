# NuKropAI Release Artifacts

## APK
- NuKropAI-release.apk — Universal release APK (all ABIs)
  - Size: ~95 MB
  - Min SDK: 24 (Android 7.0)
  - Target SDK: 36
  - **Unsigned** — for direct sideloading

## AAB
- NuKropAI-release.aab — Android App Bundle for Google Play Store
  - Size: ~60 MB  
  - Use with your keystore for signed Play Store upload

## Installation (Sideload)
1. Enable "Install from unknown sources" in Android Settings
2. Transfer NuKropAI-release.apk to your device
3. Tap to install

## Play Store
Use NuKropAI-release.aab with a signing keystore via Play Console.
